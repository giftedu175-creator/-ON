# 부산바다ON 실행 안내

## 실행 방법

별도 라이브러리 없이 HTML, CSS, JavaScript만으로 작성했습니다.

1. 이 폴더에서 터미널을 엽니다.
2. 아래 명령으로 API 프록시와 웹앱을 실행합니다.

```powershell
node server.mjs
```

3. 브라우저에서 `http://localhost:5500`을 엽니다.

`index.html` 파일을 직접 열면 `/api/ocean/buoys` 서버 경로를 사용할 수 없으므로 반드시 위 서버로 실행합니다.

## 구현 기능

- 날짜, 출발 위치, 여행 스타일, 활동을 바탕으로 부산 해양 관광 경로를 제안합니다.
- OpenStreetMap 기반의 실제 부산 지도를 표시합니다.
- 해운대·광안리·송정·다대포에 추천/주의 상태 핀을 표시합니다.
- 지도 핀을 누르면 해당 장소의 해양 상태 요약을 확인할 수 있습니다.

## 국립해양조사원 API 적용

현재 이 앱에는 API 인증키가 없어서 실제 데이터를 직접 요청하지 않았습니다. 공공데이터포털 API는 개인별 `serviceKey` 발급·승인 절차가 필요하며, 키를 브라우저 코드에 넣으면 노출되므로 서버에서 호출해야 합니다.

1. [공공데이터포털](https://www.data.go.kr)에서 회원가입 후 해양관측부이 최신 관측데이터 API를 활용 신청합니다.
   - [국립해양조사원 해양관측부이 최신 관측데이터](https://www.data.go.kr/data/15155516/openapi.do): 수온·염분·바람 등
   - [국가해양관측망 실측 파랑](https://www.data.go.kr/data/15155994/openapi.do): 파고·파주기·파향
   - [국립해양조사원 ROMS 수치예측모델](https://www.data.go.kr/data/15142227/openapi.do): 표층 수온·유향·유속 예측
2. 승인된 서비스키를 환경변수로 설정합니다.

```powershell
$env:KHOA_SERVICE_KEY='공공데이터포털에서 발급받은 서비스키'
.\run.ps1
```

`run.ps1`은 Node.js를 우선 사용하고, 없으면 Python 3로 같은 API 서버를 실행합니다.

3. 서버가 국립해양조사원 API를 호출하고 필요한 값만 `/api/ocean/buoys`로 앱에 전달합니다. 서비스키는 브라우저로 전송되지 않습니다.
4. 서버는 부산 관측소 6곳을 병렬 요청하며, 일부 실패해도 성공한 관측소 데이터를 반환합니다.

국립해양조사원 공개 API에서 이 프로젝트의 핵심 지표인 **탁도 또는 미세플라스틱 농도**를 바로 제공하는 엔드포인트는 확인되지 않았습니다. 실제 수질 연동이 필요하면 해양환경공단·지자체 수질 측정 자료를 별도 데이터 소스로 연결해야 합니다.
